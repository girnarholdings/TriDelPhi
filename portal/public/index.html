Check code before you trust it.

Use your own GitHub Codespace: a temporary development computer in your browser. TriDelPhi does not charge for this option. GitHub usage limits and charges still apply.

Checking sign-in…

1. Connect GitHub

Install the TriDelPhi GitHub App, then sign in with it. Installing the App and signing in are separate steps.

Install GitHub App Sign in with GitHub

2. Open your scanning workspace

We check that GitHub allows Codespaces for the trusted scanner repository and that your account would pay. GitHub makes the final availability and billing decision.

Review and create on GitHub

No automatic creation. No fallback to paid Cloudflare scanning. Delete your Codespace when finished; stopping it does not delete its stored files.

3. Scan inside the Codespace

Upload a ZIP or library archive into the trusted workspace, then run:

python -m tridelphi.audit ./your-project.zip

For a private GitHub repository, download its ZIP while signed into GitHub and upload it there. Do not open the untrusted target as a Codespace or run its installer.

The report stays in your Codespace. These are static checks, not antivirus or proof that code is safe.
