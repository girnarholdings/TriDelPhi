How to scan once your workspace opens

Upload your project ZIP, then run this in its terminal:

python -m tridelphi.audit ./your-project.zip

This is the same check as tridelphi audit, written so it works even when your terminal cannot find the tridelphi command. Replace the filename with yours. For a private repository, download its ZIP from GitHub first. Never run the target project’s installer or setup scripts.

Save the report and delete the workspace when finished. Stopped workspaces still use storage until deleted.
