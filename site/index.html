Find the CI job that turns a comment into RCE.

TriDelPhi reads your workflows and flags the jobs where a prompt injection or pwn-request would actually run attacker code — with your repository's secrets. No account, no network, one command.

$ pipx install tridelphi $ tridelphi .

Python 3.11+. One dependency. Reads files on disk — nothing leaves the machine.

CRITICAL
U ∩ P ∩ E
Toggle a capability off — hold at most two and the job is safe.
The rule

Two is fine. Three is an exploit.

Meta's Agents Rule of Two says an agent should hold at most two of these. A GitHub Actions job is an agent by that definition — and the danger is never one line, it's the combination.

U · UNTRUSTED

Attacker text gets in

A fork-reachable trigger plus a real path in: an injected ${{ github.event.* }}, a checkout of PR code, or an AI agent reading files the PR can edit.

P · PRIVILEGE

The job holds power

A secrets.* value, a write-scoped token, id-token: write, or a self-hosted runner — the runner itself is the prize.

E · EGRESS

It can reach out

Any run: step, a publish or deploy action, or an agent with Bash / WebFetch. On a hosted runner, a shell is the open internet.

The hard part nobody else does

It knows what each agent restores from the base branch.

Detecting "an agent runs here" is easy. Knowing which attacker-editable files the agent actually reads — after the action swaps some of them back to safe base-branch copies — is the difference between a true finding and a false alarm on a hardened repo.

CLAUDE.mdSAFE

Claude Code Action restores this from the base branch before the agent starts. A tool that flags it is crying wolf on the recommended setup.

AGENTS.mdEXPLOITABLE

Not in the restore list — it stays at pull-request head, attacker-controlled, and the agent reads it as instructions. This is the real finding.

Get started

Sixty seconds to your first scan.

1
pipx install tridelphi
Or pip install tridelphi, or uvx tridelphi . to run without installing. Python 3.11+.
2
tridelphi .
Scan the current repo. Human-readable by default; add --format html --html-file report.html for a page you can share.
3
tridelphi . --format sarif --sarif-file out.sarif
Upload to GitHub code scanning. Findings show up in the Security tab, in the PR, right where reviewers look.
4
tridelphi . --with-zizmor
Add zizmor's line-level checks — unpinned actions, mutable tags — merged into one SARIF. Complementary, not overlapping.
5
tridelphi --coverage
Map every rule onto Uber ADR's 17 agent threat techniques — and see plainly which ones static analysis cannot reach. ADR is the runtime half; this is the static half.
