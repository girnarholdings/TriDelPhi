Read someone else's code before the installer runs.

door 1 · tridelphi scan

The attack that is actually happening to people: an AI assistant hands you a download link it never verified, and the “style guide” it loads is executable instructions in disguise. scan reads the code first. It never executes it.

“The link came from inside a chat window.” A real report: someone installing a transcription app pasted the command their assistant sent. It was a copycat site bundling malware. Restoring from backup, they found a poisoned SKILL.md that looked exactly like their own style guide, with buried instructions to silently re-download the malware every time the AI loaded it. That exact attack is reproduced in TriDelPhi's test suite, and every limb of it is caught.
I

Install-time execution

Code wired to run the moment you install or open the folder: npm postinstall, setup.py, .envrc, editor auto-run tasks, shipped git hooks.

D

Download-and-run

curl | bash, PowerShell cradles, fetch → chmod → execute. The server decides what runs on your machine.

O

Obfuscation

Base64 piped to a shell, eval(atob()), and invisible Unicode: you read one thing, the interpreter reads another.

C

Credential reach

Reads of ~/.ssh, cloud credentials, browser logins, wallets, graded up when the same file also phones home. A read plus a send is exfiltration's exact shape.

A

Poisoned agent files

SKILL.md, CLAUDE.md, .cursorrules, .mcp.json: secrecy instructions near an action, imperatives hidden in HTML comments.

L

Dishonest links

Link text naming one domain, the URL going to another. Raw-IP, shortener and throwaway-host code sources. The copycat-site trick, mechanized.

./a-directory/ a clone or unpacked download ./package.tgz archives: .tgz .zip .whl npm:pkg · tarball fetched, no scripts run pypi:pkg · plain download, never pip

The same line means different things in different files, so install context is the severity dial: curl | bash in a README is a warning, because a README doesn't run itself. The same line in a postinstall or an agent file is critical.

Archives are extracted safely first: an archive built to escape its extraction directory is refused, and the refusal is the verdict. The registry forms (npm: / pypi:) are the tool's only network use. Download only, announced before connecting, and never pip download, which can execute a hostile setup.py just to read metadata.

A clean result means no known-bad patterns in the source we read. It is never a certificate for a compiled binary or tomorrow's server response, and the report says so on every run.

Two powers is fine. All three together is a disaster.

door 2 · tridelphi . · the Agents Rule of Two

Every GitHub robot can hold up to three powers. On their own, none is scary. The trap is a single robot holding all three at once: that's the recipe a stranger needs. Tap a power to switch it off and watch the danger vanish.

Tap any circle to toggle that power on or off.
U

It reads words from strangers

Anyone on the internet can leave a comment or suggest a change, and that text reaches the robot.

P

It holds your keys

Your passwords, secret keys, or permission to change things. The prize a stranger is after.

E

It can reach the internet

So it can send things out, which is exactly how your keys would leave if it were tricked.

Any two of these is a normal, safe robot. Put all three in one robot and a stranger's comment becomes a way to walk off with your keys. TriDelPhi finds those robots, including the ones built from AI agents, where the “comment” becomes the agent's instructions. Removing any one power breaks the chain, and the report always names the cheapest one to remove.

From finding to fixed, without leaving the terminal

tridelphi fix prints the exact remediation plan; tridelphi guard walks each finding with you and applies the fix when you say yes. Every edit is verified against a re-scan or rolled back.

$tridelphi guard

No CI? No problem.

init --local installs a git pre-push hook that runs the same checks on your machine before every push. (Not pre-commit: a scan people bypass is no scan.) Zero GitHub Actions required.

$tridelphi init --local

Your CI can be spotless while your product leaks.

door 3 · tridelphi expose

The exposure audit reads what you actually ship: the built bundle, the config, the data files. Then it names what a stranger with a browser could take.

Shipped source maps & client secrets

Your original source riding along with the minified bundle; API keys baked into JavaScript anyone can read.

Weak password hashing & plaintext PII

MD5/SHA-1 where bcrypt belongs; personal data sitting unencrypted in shipped files.

Open databases & risky config

Firebase and Supabase rules that let anyone read; self-hosted databases listening to the world.

And when you have a reason to hide your shipped JavaScript, tridelphi privatize obfuscates it honestly: opt-in, consent-gated, and every build verified afterwards, or the change is reverted. Obfuscation is a speed bump, not a safe; the report never pretends otherwise.

What you see (--min-severity) and what breaks the build (--fail-on) are separate dials. You never have to choose between seeing near-misses and having a green build. A baseline file lets old findings age out without hiding new ones.

Every technical word on this page, in one place.

Robot (workflow / action)
A helper GitHub runs for your project: testing code, replying to comments, doing chores. Defined by files in .github/workflows.
CI
“Continuous integration”, the umbrella term for those robots running automatically on every change.
Keys / secrets
Passwords, API tokens and permissions your project holds. The thing every attack on this page is ultimately after.
Prompt injection
Tricking an AI by hiding instructions in text it reads: a comment, a README, a “style guide”. The AI can't tell your words from a stranger's.
Agent file
A file an AI assistant loads as instructions: SKILL.md, CLAUDE.md, .cursorrules, .mcp.json. Executable code wearing a markdown extension.
Install hook
A script that runs automatically the moment you install a package, like npm's postinstall or Python's setup.py. The most-used malware delivery slot.
Supply-chain attack
Compromising you by compromising something you install or depend on, instead of attacking you directly.
RCE
“Remote code execution”: a stranger running their commands on your machine. The worst case everything here works to prevent.
PR (pull request)
A proposed change to a project. Anyone can open one, which is exactly why robots that read them must be careful.
SARIF
The standard file format security tools use to report findings. It's how TriDelPhi feeds GitHub's Security tab.

$pipx install git+https://github.com/girnarholdings/TriDelPhi

Scan a download before installing it, check your own repo, or audit your built app. Each is one command with a plain-English verdict.

$tridelphi scan npm:some-package

$tridelphi init
